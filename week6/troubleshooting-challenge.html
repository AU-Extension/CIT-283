Network troubleshooting challenge

You are on the Sunrise Logistics help desk. Ten tickets are waiting. For each one, run show commands to gather evidence, then choose the root cause and the fix. Good technicians find the problem with as few commands as possible.

How to use this interactive
  1. Read the user complaint and the facts you already know.
  2. Click commands to run them. The output appears in the terminal. Each ticket has a par: the number of commands an experienced technician needs.
  3. Choose the root cause and fix, then press Submit. A correct first answer earns up to 10 points, minus 1 for each command beyond par (never below 5). A correct second answer earns up to 5 points.
  4. Read the explanation after each ticket. It shows which output gave the problem away and the commands that fix it.
