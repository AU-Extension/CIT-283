NSG rule evaluator

A network security group (NSG) is Azure's firewall for a subnet or a VM. Azure checks its rules from the lowest priority number to the highest and stops at the first rule that matches. Read rule lists like Azure does, then write your own rules to protect a database. Three levels, 100 points.

How to use this challenge
  1. Levels 1 and 2: for each traffic flow, pick the rule that decides it, then press Lock in. Each correct answer is worth 5 points and you get one try.
  2. After each answer, read the trace. It shows every rule Azure checked, in order, and why it did or did not match.
  3. Level 3: add your own rules to the database NSG, then press Check rules. Eight test flows run against your list. The level is worth 40 points, minus 5 for each check that fails (minimum 16).
  4. Remember the three default rules at the bottom of every NSG. You cannot delete them, but rules with lower numbers run first.

How Azure evaluates an NSG

  1. Only rules for the traffic direction count (inbound or outbound).
  2. Rules are checked from priority 100 upward. Priorities run from 100 to 4096 for your rules.
  3. A rule matches when the source, destination, protocol and port all match.
  4. The first matching rule wins. Nothing after it is checked.
  5. If none of your rules match, the default rules decide (65000, 65001, 65500).
