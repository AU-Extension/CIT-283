Routing table explorer

Sunrise Logistics has a headquarters in Miami and branches in Fort Lauderdale and Homestead. Click any router to read its routing table, then send a packet and watch each router pick the longest matching route, one hop at a time.

How to use this interactive
  1. Pick a scenario. Start with the complete network, then try the broken ones.
  2. Click a router in the diagram (or use the tabs) to see its show ip route output.
  3. Choose a source PC and a destination, then press Trace packet. Use Next step to move one router at a time.
  4. At each router, read the table of matching routes. The longest prefix (the biggest /number) always wins.
  5. Remember that a ping needs two trips: the request and the reply. Watch for the reply failing.
  6. Finish with the six quick questions at the bottom.
