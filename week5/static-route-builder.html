Static route builder

Type real ip route commands on the Sunrise Logistics routers until every office can reach every other office. Four levels take you from two routers to a network with an ISP and floating backup routes. Each level is worth 25 points.

How to use this interactive
  1. Read the goal for the level. Click a router (or its tab) to open its configuration prompt.
  2. Type a command such as ip route 192.168.20.0 255.255.255.0 10.0.0.2 and press Enter. Use no ip route ... or the Remove button to delete a route.
  3. Watch the connectivity matrix. Green means the ping works in both directions. Click any red cell to see where the packet was dropped.
  4. Press Check level when the matrix is green. Each failed check costs 3 points, each hint costs 5, and showing the solution gives 0 points for that level.
  5. Your routes carry forward to the next level, just like a real network that grows over time.

Command pattern: ip route <network> <subnet-mask> <next-hop-ip | exit-interface> [distance]. The mask must be dotted decimal (255.255.255.0), not /24.
