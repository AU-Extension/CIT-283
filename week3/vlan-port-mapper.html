VLAN port mapper

A switch sends a broadcast to every port in the same VLAN and to no other port. Assign the eight office PCs to VLANs, send broadcasts, and watch the broadcast domains change. The Cisco IOS commands and the show vlan brief output update as you work.

How to use this interactive
  1. Every PC starts in VLAN 1, the default VLAN, so the whole switch is one broadcast domain. Press Broadcast next to any PC to see who receives it.
  2. Change the VLAN of each PC with its drop-down list (you can also click a port on the switch drawing to jump to that PC).
  3. Send broadcasts again. Only PCs in the same VLAN receive them.
  4. Turn on Park and shut down unused ports to place ports Fa0/9 to Fa0/24 and Gi0/1 to Gi0/2 in VLAN 99 and disable them.
  5. Open the IOS commands and show vlan brief tabs to read the configuration that matches your choices. Complete the four goals and the quick check at the bottom.

enable / configure terminal
Move from user mode to privileged mode, then to global configuration mode, where changes are made.

        
vlan 10
Creates VLAN 10 (or opens it if it exists) and enters VLAN configuration mode.

        
name Sales
Gives the VLAN a readable name. Names help the next technician understand the design.

        
interface FastEthernet0/1
Selects one port. interface range FastEthernet0/1 - 2 selects several ports at once, which saves typing.

        
switchport mode access
Makes the port an access port: it belongs to exactly one VLAN and connects an end device such as a PC or printer.

        
switchport access vlan 10
Places the access port in VLAN 10. Frames from the PC on this port are now part of VLAN 10.

        
shutdown
Disables the port. Unused ports are parked in an unused VLAN and shut down so nobody can plug in and join a real VLAN.

        
end / copy running-config startup-config
Return to privileged mode and save the configuration so it survives a reload.

        
show vlan brief
Lists every VLAN, its name, its status and the access ports assigned to it. It is the first command to run when checking VLAN work.
