Trunk and inter-VLAN routing challenge

Eight help desk tickets, each caused by one or two configuration mistakes on a small office network with two switches and a router-on-a-stick. Change the settings, run the test ping, and watch the frame travel, gaining and losing its 802.1Q tag as it crosses each trunk.

How to use this interactive
  1. Read the ticket and look at the topology. Every PC uses a /24 network and its VLAN number as the third octet (VLAN 10 is 192.168.10.0/24).
  2. Run the test ping first to see where the frame stops. The step list explains why it failed.
  3. Change only the settings you think are wrong, then run the test again. The configuration tabs show the matching Cisco IOS lines.
  4. Each ticket is worth 100 points. A failed test costs 20 points and a hint costs 10, with a minimum of 40 points for a solved ticket.
  5. Your total appears after the last ticket. You can restart at any time.
