Subnetting speed drill

Ten questions per round: network and broadcast addresses, host ranges, host counts, masks and subnet counts. Every answer comes with a worked solution, so a wrong answer still teaches you the method.

How to use this interactive
  1. Pick a level. Level 1 keeps all the math in the last octet, which is where most beginners should start.
  2. Press Start round. Type each answer and press Enter. IP answers need all four octets.
  3. Use Hint if you are stuck, or Show me to see the full solution (it counts as a miss).
  4. Read the worked solution after every question, even the ones you got right.
  5. Aim for 9 or 10 on Level 1 before moving to Level 2. Your best score per level is remembered on this device.
