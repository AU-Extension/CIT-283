Subnet visualizer

Drag the prefix and watch one address block split into equal subnets, with every network, host range and broadcast listed. Then switch to VLSM and give each department a block sized to its needs.

How to use this interactive
  1. Type a starting network such as 192.168.10.0 and choose its prefix (/24 for a typical office).
  2. Drag the new prefix slider to the right. Each step borrows one more host bit and doubles the number of subnets.
  3. Watch the purple borrowed bits, the block size and the subnet table change together. Click any subnet to highlight it.
  4. Read the block size method panel and try to predict the next row of the table before you look.
  5. Open the VLSM tab, enter departments and their host counts, and press Allocate largest first.

    How VLSM works

    1. Sort the departments from the most hosts to the fewest.
    2. For each one, find the smallest number of host bits h where 2h minus 2 is at least the hosts needed. The prefix is 32 minus h.
    3. Give it the next free block of that size, starting at the beginning of the address space.
    4. Because the biggest blocks go first, every block starts on a correct boundary and nothing overlaps.
    5. Whatever is left at the end is free space for growth or for point-to-point links.
