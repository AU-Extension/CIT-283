Week 7 · Explorer

Hyper-V virtual switch explorer

Plug four virtual machines into different Hyper-V virtual switches and watch what each one can reach: the host computer, the office network, the internet and the other VMs. Every change also shows the PowerShell command an administrator would type.

How to use this interactive
  1. In the virtual machines panel, pick a virtual switch for each VM. Start with all four on the same switch, then move them around.
  2. Read the reachability matrix. Click any cell to get a plain-language reason.
  3. Use "Ping" to send an animated test packet from a VM to a target and see where it stops.
  4. Turn NAT on and off for the Lab-Internal switch, and type VLAN IDs to see how they split one switch into separate groups.
  5. Copy the PowerShell commands from the log into your notes for Assignments 7.1 and 7.2.

The lab

On a small screen, scroll the diagram sideways. Lines from each VM show which switch its virtual network adapter is connected to.

Virtual machines

The host gets 192.168.50.1 on its vEthernet (Lab-Internal) adapter and translates VM traffic to its own address, so VMs on Lab-Internal can reach the internet.

Switch types at a glance

SwitchWhat it connects
ExternalBound to a physical network card. VMs act like real computers on the office LAN and get addresses from the office DHCP server.
InternalVMs and the host only. Add NAT (New-NetNat) to give VMs internet access through the host.
PrivateVMs only. Not even the host can reach them. Good for isolated test labs.
Default SwitchCreated by Windows automatically. Built-in NAT and DHCP, so VMs reach the internet, but office devices cannot start connections to them.
Get-VMSwitch New-VMSwitch -Name "Lab-External" -NetAdapterName "Ethernet" -AllowManagementOS $true New-VMSwitch -Name "Lab-Internal" -SwitchType Internal New-VMSwitch -Name "Lab-Private" -SwitchType Private

Simplification used here: the host and the office LAN are untagged (no VLAN). A VM with a VLAN ID can only talk to VMs with the same VLAN ID on the same switch.
