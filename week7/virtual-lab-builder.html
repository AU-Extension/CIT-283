Virtual lab builder challenge

You are the network administrator for a small Miami company that runs its servers as Hyper-V virtual machines. Each mission gives you requirements. Choose the virtual switch, VLAN ID and IP settings for every VM so the requirements pass. Six missions, 100 points.

How to use this challenge
  1. Read the mission brief and the list of requirements. Some say a connection must work, others say it must be blocked.
  2. Configure each VM. IP fields only matter on Lab-Internal and Lab-Private, because those switches have no DHCP server. External and Default Switch VMs get addresses automatically.
  3. On Lab-Internal, the host adapter vEthernet (Lab-Internal) is 192.168.50.1/24. Decide if NAT should be on.
  4. Press "Check my design". Each failed check costs points, so think before you click. After two failed checks you can reveal the answer, but the mission then scores zero.
  5. Your final score appears after mission 6. Take a screenshot of it for your records.
Score0/ 100

Mission points shrink by 4 for each failed check, down to a minimum of 40% of the mission value.

Rules this lab follows

SwitchReaches
Lab-ExternalHost, office LAN (both directions), internet. DHCP from the office router.
Lab-InternalHost and VMs on the same switch. Internet and office LAN only outbound, and only with NAT plus gateway 192.168.50.1. Static IPs.
Lab-PrivateVMs on the same switch only. Static IPs.
Default SwitchHost, internet through NAT, office LAN outbound only. Automatic addressing.

VMs on different switches never talk (no router in this lab). VLAN IDs must match. The host and office LAN are untagged.
